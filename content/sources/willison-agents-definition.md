## Summary

A short post settling on a one-line definition of an LLM agent, and explaining each part of it: tools, the loop, and the goal that makes the loop stop.

## Key claims

- The definition. "An LLM agent runs tools in a loop to achieve a goal." (main text)
- The loop feeds results back: "the outcome of those tools is fed back into the model so it can continue to reason through and solve the given problem." (main text)
- The goal is the stop. "'To achieve a goal' reflects that these are not infinite loops—there is a stopping condition." (main text)
- Memory for free. The loop "has a fundamental form of memory baked in": the earlier steps of the conversation serve as short-term memory. (main text)
- He rejects "agents that replace humans" as a definition: "This category of agent remains science fiction." (main text)
