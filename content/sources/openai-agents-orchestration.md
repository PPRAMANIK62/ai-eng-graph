## Summary

OpenAI's current docs on splitting work between agents: handoffs (control moves to a specialist) vs agents as tools (a manager keeps control), and a clear default to start with one agent. Undated.

## Key claims

- Handoffs: "Control moves to the specialist agent". Agents as tools: "The manager keeps ownership of the reply". (Orchestration and handoffs)
- Default. "Start with one agent whenever you can. Add specialists only when they materially improve capability isolation, policy isolation, prompt clarity, or trace legibility." (same)
- Cost of splitting. "Splitting too early creates more prompts, more traces, and more approval surfaces without necessarily making the workflow better." (same)
